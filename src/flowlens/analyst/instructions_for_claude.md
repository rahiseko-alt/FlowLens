# Claude Code への指示書（FlowLens 分析）

このフォルダで Proposal Report（ご提案書）を書いてください。

## 読むもの

- 読むのは `analysis_summary.json` と `confirmation_questions.md` だけです。
- このフォルダの外、特に名前が `_do_not_send_to_ai` で終わるフォルダは、開かず、読まず、引用しないでください。

## 守ること

- 数字は `analysis_summary.json` にある値だけを使ってください。数字を計算し直したり、作ったりしないでください。
- 月あたりの時間などの推定は、必ず「推定値」と書き、`formula` の計算式を添えてください。推定の無い候補は、回数と日数で説明してください。
- 個人を比べたり、順位を付けたりしないでください。複数人のときは「何人に見られたか」（`people`）だけを書いてください。
- 「ファイル A」「画面 B」は呼び名です。中身は分かりません。中身を推測で決めつけず、「確認したいこと」に回してください。
- `contained_in` がある候補は、そこに書かれた長い流れの一部です。時間が重なるので、長い流れと合計しないでください。両方を挙げるなら「一部が重なる」と書いてください。
- 候補は種類ごとに上位5件までです。載せなかった数は `candidates_left_out` にあります。必要なら「ほかに○件」と書いてください。
- `basis.notes` に注意書きがあれば、提案書の冒頭に書いてください。

## 書くもの（Proposal Report）

1. 前提: 期間、人数、記録分の日数、読めなかった過去分の元（`basis`, `past.unreadable_sources`）
2. 時間の使い道: アプリごとの時間、曜日×時間帯の傾向（`live`, `past`）
3. 自動化の候補: `candidates` から効果の大きい順に 3〜5 件。各件に、何の作業と思われるか（推測は推測と書く）、根拠の数字（回数・日数・1回の時間・推定時間と計算式）、自動化の案
4. 確認したいこと: `confirmation_questions.md` の質問をそのまま付け、必要なら補ってください
