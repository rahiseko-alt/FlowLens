# 0005 単独実行ファイル化とインストーラーの選定

## 状況

FlowLens Collector は、クライアント企業の社員が自らの PC に導入して業務記録を収集する常駐ツールである。
以下の要件を満たす配布・インストール方式を選定する必要がある。

1. **Python 環境の非依存**: 対象 PC に Python 3.12 や pip、ビルドツールが導入されていない環境でも、インストーラーを実行するだけで動作すること。
2. **一般ユーザー権限での導入**: 社員本人によるインストールを前提とするため、管理者権限（UAC 昇格）を要求せず、一般ユーザー権限（ユーザープロファイル配下: `%LOCALAPPDATA%\Programs\FlowLens`）で完結すること。
3. **利便性と常駐性**: スタートメニューへの登録および Windows ログイン時の自動起動（HKCU Run キー）が行われること。
4. **データの保持選択**: アンインストール時に、記録データ（`%LOCALAPPDATA%\FlowLens`）を消去するか、分析用に残すかを社員が選択できること。
5. **外部通信の完全排除**: インストーラーや配布バイナリに、アップデータ、REST 通信、テレメトリ、クラウド接続部品が一切含まれないこと。

## 検討した選択肢

### 1. 実行ファイル化方式（Python Bundler）
- **PyInstaller**: Python コミュニティで最も実績があり、C 拡張モジュール（`pywin32`, `pyzipper` 等）の依存性解決が自動で行われる。1つの実行ファイル（onefile）または展開済みディレクトリ（onedir）を生成可能。
- **Nuitka**: Python コードを C++ に変換してコンパイルするため高速だが、ビルド環境に MSVC / MinGW が必須で依存ライブラリのフック保守コストが高い。
- **cx_Freeze / py2exe**: 更新頻度および Windows 11 の最新 API 対応において PyInstaller に劣る。

### 2. インストーラー作成方式
- **Inno Setup**: オープンソース（ISSL ライセンス）で軽量。非管理者権限インストール（`PrivilegesRequired=lowest`）を標準サポートし、アンインストール時のカスタムダイアログ（データ削除の確認）を Pascal スクリプトで容易に実装できる。
- **WiX Toolset (MSI)**: Windows インストーラーの標準だが、一般権限でのショートカット配置やレジストリ設定、アンインストール時の動的データ保持ダイアログの記述が複雑。
- **ポータブル ZIP 配布のみ**: インストーラー不要だが、スタートメニュー登録や自動起動、アンインストールの手順が社員の手作業となり導入障壁が高い。

## 決定事項

1. **PyInstaller による単独バイナリ（onedir / onefile）化**:
   - `flowlens.spec` を作成し、Collector 本体および依存ライブラリ（`pyzipper`, `pywin32`）を Python 不要の実行ファイル群にパッケージングする。
   - 通信ライブラリや外部 SDK を含まない最小構成を保証する。
2. **Inno Setup によるユーザー権限インストーラー（`flowlens_setup.iss`）**:
   - `PrivilegesRequired=lowest` を指定し、管理者権限なしで `%LOCALAPPDATA%\Programs\FlowLens` にインストール。
   - スタートメニューにショートカットを作成し、HKCU Run キーに自動起動を登録。
   - アンインストーラー実行時にメッセージボックスを表示し、記録データ（`%LOCALAPPDATA%\FlowLens`）を「消去する」か「残す」かを社員が選択できる設計とする。
3. **Python 内部インストーラー/アンインストーラーの補助実装（`src/flowlens/windows/installer.py`）**:
   - テスト自動化およびスクリプト実行環境向けに、Inno Setup と同等のショートカット作成・自動起動登録・データ消去選択を行えるPythonモジュールも提供する。
4. **ライセンスの同梱**:
   - 配布物に FlowLens のライセンスおよび DeskMate の MIT ライセンス表示（`LICENSE`）を同梱する。

## 結果（Consequences）

- 社員は管理者権限を申請することなく、ダウンロードしたインストーラーをクリックするだけで導入できる。
- アンインストール時に「データを消して痕跡を残さない」か「コンサルタントに渡すためデータを残す」かを確実に制御できる。
- 外部通信モジュールが混入しないことが保証される。
