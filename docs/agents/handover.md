## 2026-09-28 分析コマンドを作った（#34〜#41）

**決めたこと**

- `python -m flowlens.analyst 書き出し.zip ... --out フォルダ` で、要約・確認リストの下書き・Claude Code への指示書・呼び名の対応表（AI に渡さない。出力フォルダの隣の `_do_not_send_to_ai` フォルダに置く）が出る。手順は `docs/consultant-guide.md`
- 候補は3種類: 定時のファイル（過去分）、操作の流れ、転記（記録分）。一瞬だけの表示（5秒未満）は流れから除き、2分より長い空白で流れを区切る
- 短い流れは、長い流れの中でしか起きないなら出さない。単独でも起きるなら、どの長い流れに含まれるかを添えて出す（時間を二重に足さないため）
- 同じ人の期間の重なる書き出しは、1人分にまとめてから数える

**次にやること**

- 利用者の実データ（自分の PC の書き出し）で分析コマンドを試し、基準（回数・日数・5秒・2分）を見直す
- Claude Code に指示書どおり提案書を書かせ、出来を確かめる

**未解決の問題**

- 実データで、呼び名だけの要約から業務を見分けられるかは未確認
- 分析コマンドを動かすには、この置き場所のプログラム（Python 3.12）が要る。コンサルタントの PC への入れ方はまだ決めていない
