# #14 Past Import の中核: 過去記録を区別して取り込む

## Parent

https://github.com/rahiseko-alt/FlowLens/issues/3

## What to build

読み込み元ごとの偽の過去記録（使用時間、PC を使っていた時間帯、開いたファイル、訪れたサイト）を中核に流すと、最小データ原則を通したうえで「過去分」と「読み込んだ元」つきで保存され、書き出したファイルに入る（ADR 0004）。選ばれた元だけを読み、元ごとに独立して失敗でき、後から外した元を追加で読める。

## Acceptance criteria

- [ ] 過去分は記録分と区別され、読み込んだ元が分かる
- [ ] ファイル名・題名は記号と拡張子になり、閲覧履歴はドメインだけになる（生の文字列を検索しても見つからない）
- [ ] 選ばれていない元は読まれない
- [ ] 1つの元が失敗しても他の元は取り込まれ、元ごとの件数と読めなかった理由が残る
- [ ] 後から追加で読み込んでも、既に取り込んだ分が二重にならない
- [ ] 除外アプリの過去分も除かれる
- [ ] 過去30日より古い記録は取り込まない
