# #6 離席を App Session から除く（idle・ロック・スリープ・切断）

## Parent

https://github.com/rahiseko-alt/FlowLens/issues/3

## What to build

偽の idle・ロック・スリープ・セッション切断の観測を流すと、その時間が App Session に含まれず、書き出したファイルで作業時間として数えられない。

## Acceptance criteria

- [ ] App Session の途中に5分の idle を挟むと、App Session が分かれ、idle の時間を含まない
- [ ] ロック・スリープ・切断の時間も同様に含まれない
- [ ] 復帰後、前面にあるアプリの App Session が新しく始まる
- [ ] idle とみなすまでの時間は設定値で、初期値を持つ
