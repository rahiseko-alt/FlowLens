# #18 常駐アイコンと初回の同意画面

## Parent

https://github.com/rahiseko-alt/FlowLens/issues/3

## What to build

ユーザーのセッション内で動く常駐アプリにする。初回は説明画面（目的、PC 内に保存、AI・外部送信なし、文字は残らない、いつでも止められる、過去30日分も読むこと、読み込む元の一覧と元ごとの選択）を出し、同意するまで記録も読み込みもしない。同意すると Past Import と Live Capture が始まる。画面右下のアイコンで記録中／一時停止中が分かり、一時停止・再開ができる。状態の画面、ログイン時の自動起動、二重起動の防止、止まった処理の自動復旧を持つ。

## Acceptance criteria

- [ ] 同意前は何も記録・読み込みされない
- [ ] 読み込む元は初期状態ですべて選択され、外した元は読まれない
- [ ] 読み込みの進み具合と、元ごとの件数・読めなかった理由が表示される
- [ ] アイコンで記録中／一時停止中が見分けられ、一時停止・再開ができる
- [ ] 状態の画面に、記録中か・収集開始日・記録済み時間・データ使用量が出る
- [ ] ログインで自動起動し、二重に起動しない
- [ ] 強制終了・スリープ・再起動のあとに自動で記録が再開される
- [ ] 障害調査用のログに業務データや入力内容が出ない
