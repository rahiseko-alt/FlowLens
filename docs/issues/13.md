# #13 summary.json（アプリごとの時間と転記回数）

## Parent

https://github.com/rahiseko-alt/FlowLens/issues/3

## What to build

書き出したファイルに、AI を使わず集計で作った `summary.json` が入る。合計の作業時間、アプリごとの時間と起動回数、アプリ間の転記回数（例: `"Chrome->Excel": 218`）を持つ。過去分と記録分は分けて集計する。

## Acceptance criteria

- [ ] 偽の観測から期待どおりの合計時間・アプリごとの時間・起動回数が出る
- [ ] Clipboard Transfer からアプリ間の転記回数が出る
- [ ] 過去分と記録分が別々に集計されている
- [ ] 除外中・idle の時間は作業時間に入らない
