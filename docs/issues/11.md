# #11 除外アプリと一時停止、書き出し時の再無害化と redaction_report

## Parent

https://github.com/rahiseko-alt/FlowLens/issues/3

## What to build

除外アプリを設定すると、そのアプリが前面の間の操作・Clipboard・URL・題名はどれも残らず、「除外中だった時間」だけが残る。一時停止中は何も残らず、一時停止していた時間だけが残る。書き出し時にも同じ規則をもう一度かけ、除外したものの件数を `redaction_report.json` に入れる。

## Acceptance criteria

- [ ] 除外アプリの偽の観測を流しても、書き出したファイルにそのアプリの操作・Clipboard・URL・題名の記号が無く、除外中の時間だけがある
- [ ] Clipboard Transfer の元か先が除外アプリなら、その件は残らない
- [ ] 一時停止から再開までの観測は残らない
- [ ] 保存後に除外を追加した場合も、書き出したファイルからそのアプリの記録が除かれる
- [ ] `redaction_report.json` に件数だけが入り、中身は入らない
