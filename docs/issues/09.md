# #9 Clipboard Transfer を記録し、中身は残さない

## Parent

https://github.com/rahiseko-alt/FlowLens/issues/3

## What to build

偽の Copy / Cut と Paste の観測を流すと、組になった Clipboard Transfer（時刻、元のアプリ、先のアプリ、種類、長さ）が保存される。Clipboard の中身は保存されない。Paste を直接検出できない場合は Ctrl+V の Operation Type で補う。

## Acceptance criteria

- [ ] 中身を含む偽の Copy 観測を流しても、書き出したファイル全体を検索して中身が見つからない
- [ ] Chrome で Copy → Excel で Paste が、元 Chrome・先 Excel の1件として残る
- [ ] 種類と長さが残る
- [ ] Paste の観測が無く Ctrl+V だけがある場合も組が作られる
- [ ] 対応する Paste が無い Copy も記録される（先のアプリは空）
