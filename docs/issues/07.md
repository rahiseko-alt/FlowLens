# #7 ウィンドウタイトルを鍵付きの記号と拡張子にする（ADR 0003）

## Parent

https://github.com/rahiseko-alt/FlowLens/issues/3

## What to build

観測に含まれるウィンドウタイトルが、中核で PC 内の鍵を使ったハッシュと拡張子に置き換えられ、生の文字列は保存も書き出しもされない。同じ題名は同じ記号になる。

## Acceptance criteria

- [ ] 「○○商事_見積.xlsx - Excel」を含む偽の観測を流しても、書き出したファイル全体を文字列検索して「○○商事」「見積」が見つからない
- [ ] 同じ題名は同じ記号、違う題名は違う記号になる
- [ ] 拡張子（例: `.xlsx`）が読み取れる場合は別の項目として残る
- [ ] 鍵は書き出したファイルに含まれない
- [ ] 鍵は PC 内で一度作られ、再起動しても変わらない
