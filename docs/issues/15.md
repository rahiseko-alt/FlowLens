# #15 Windows の入口: 前面アプリ・idle・ロック・スリープ

## Parent

https://github.com/rahiseko-alt/FlowLens/issues/3

## What to build

本物の Windows で、前面ウィンドウの切り替え・idle・ロック・スリープ・切断を検出して中核に流す薄い入口を作る。DeskMate の `win_events` と `activity_feed` を流用し、ロック・スリープ・切断は新規に作る（`docs/research/deskmate-survey.md`）。入口は判断をせず観測を渡すだけ。

## Acceptance criteria

- [ ] 実機で Chrome → Excel → Outlook と切り替えると、その順の App Session が書き出したファイルに入る
- [ ] 実機でロック・スリープを挟むと、その時間が App Session に入らない
- [ ] 入口が題名の生の文字列を保存しない（中核に渡すだけ）
- [ ] 実機での確認手順が手順書に残っている
- [ ] 流用した DeskMate のコードに MIT のライセンス表示が残っている
