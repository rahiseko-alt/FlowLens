# #20 設定・削除・書き出しの画面

## Parent

https://github.com/rahiseko-alt/FlowLens/issues/3

## What to build

常駐アイコンから開ける画面を作る。記録しないアプリの設定、保存期間の設定、記録データの削除（範囲選択と確認つき）、「診断データを書き出す」（期間の選択 → パスワードの入力 → 手元に1ファイル保存）。

## Acceptance criteria

- [ ] 除外アプリを追加・削除でき、すぐ記録に効く
- [ ] 保存期間を 30／60／90日／無期限から選べる
- [ ] 削除は範囲を選び、確認のあとに実行される
- [ ] 書き出しは期間（過去7／14／30日／すべて／日付指定）とパスワードを入れるだけで1ファイルが手元に保存され、保存先が表示される
- [ ] 社員に AppData などを開かせる操作を求めない
