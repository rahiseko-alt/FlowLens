# #12 記録データの削除と保存期間による自動削除

## Parent

https://github.com/rahiseko-alt/FlowLens/issues/3

## What to build

「今日／過去7日／過去30日／すべて」の範囲で記録データを削除できる。保存期間（30／60／90日／無期限、初期値30日）を過ぎた記録は自動で消える。どちらもすべての記録（Past Import 分を含む）が対象になる。

## Acceptance criteria

- [ ] 範囲を指定して削除すると、その範囲の記録だけが消え、書き出したファイルにも現れない
- [ ] 保存期間を過ぎた記録が自動削除で消える。無期限では消えない
- [ ] 削除は外部キーなどで途中で止まらない（DeskMate で起きた不具合を繰り返さない）
- [ ] 削除後にデータ使用量が減る
