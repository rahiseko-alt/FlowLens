# #5 最小の一本道: 偽の前面アプリ切り替え → 暗号化された Diagnostic Export

## Parent

https://github.com/rahiseko-alt/FlowLens/issues/3

## What to build

記録の中核と、そのテストの当て所を作る。偽の「前面アプリの切り替え」の観測を中核に流すと App Session として保存され、期間とパスワードを指定して書き出すと、AES-256 で暗号化された1ファイル（SQLite と `manifest.json` 入り）ができる。テストはそのファイルを開き、中身だけを確かめる。以降の作業単位はすべてこの当て所を使う。

## Acceptance criteria

- [ ] 「Chrome → Excel → Outlook」の偽の観測を流すと、その順・その時間の App Session が書き出したファイルの SQLite に入っている
- [ ] 書き出したファイルは指定したパスワードで開け、AES-256 で暗号化されている（独自方式ではない、実績のある部品を使う）
- [ ] `manifest.json` に版・期間・件数・ランダムな機器 ID が入り、PC 名とユーザー名を含まない
- [ ] 指定期間外の記録は含まれない
- [ ] 保存は SQLite（WAL）で、スキーマの版を持つ
- [ ] 中核の依存に通信する部品が無い
