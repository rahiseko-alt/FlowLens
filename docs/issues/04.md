# #4 実機調査: Past Import の読み込み元が読めるか

## Parent

https://github.com/rahiseko-alt/FlowLens/issues/3

## What to build

Windows 実機で、ADR 0004 に挙げた Past Import の読み込み元（システム・セキュリティのイベントログ、SRUM、UserAssist、最近使ったファイル・ジャンプリスト、Office の最近使ったファイル、Chrome / Edge の閲覧履歴）について、実際に何がどの期間読めるか、管理者権限が要るかを確かめ、結果を記録する。利用者の Windows PC での作業が要る。

## Acceptance criteria

- [ ] 元ごとに「読めたか」「読めた項目」「遡れた期間」「管理者権限の要否」が記録されている
- [ ] 社員本人が管理者権限なしでインストールした場合に読める元の一覧がある
- [ ] 結果に合わせて ADR 0004 の表が更新されている（実機の Windows の版を併記）
- [ ] User Content を含む元（例: 閲覧履歴のクエリ）が最小データ原則で捨てられる形で読めることを確かめている

## Blocked by

- None (can start immediately)
