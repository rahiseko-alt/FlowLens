# #17 Past Import の読み込み元（Windows 側）

## Parent

https://github.com/rahiseko-alt/FlowLens/issues/3

## What to build

実機調査で読めると確かめた Past Import の読み込み元について、本物の Windows の記録を読んで中核に流す薄い入口を作る。管理者権限が要る元は、権限が無いときに「読めなかった理由」として扱う。ブラウザの閲覧履歴は写しを取って読む。

## Acceptance criteria

- [ ] 実機調査で読めると分かった元ごとに入口がある
- [ ] 実機で過去30日分が取り込まれ、書き出したファイルに過去分として入る
- [ ] 管理者権限が無い場合、その元は失敗として記録され、他の元は取り込まれる
- [ ] ブラウザを使用中でも閲覧履歴が読める
- [ ] 入口が本文・URL のクエリ・生の文字列を保存しない（中核に渡すだけ）
- [ ] 実機での確認手順が手順書に残っている
