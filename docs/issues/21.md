# #21 インストーラー・アンインストーラーと通信なしの確認

## Parent

https://github.com/rahiseko-alt/FlowLens/issues/3

## What to build

Python 不要の1つの実行ファイルとインストーラーを作る。まとめ方（PyInstaller、Nuitka、Inno Setup、WiX 等）は依存を確かめて選び、理由を ADR に残す。スタートメニューへの登録とログイン時の自動起動の登録を行う。アンインストールでは記録データを消すか残すかを選べる。Collector が外部と通信しないことをテストで確かめる。

## Acceptance criteria

- [ ] Python の入っていない Windows 実機にインストーラーだけで入る
- [ ] スタートメニューから開け、ログインで自動起動する
- [ ] アンインストールで、記録データを消すか残すかを選べ、選んだとおりになる
- [ ] 記録・Past Import・書き出しの間に外部への接続が無いことをテストで確かめている
- [ ] 配布物に通信する部品（REST、AI、更新確認等）が含まれない
- [ ] DeskMate の MIT ライセンス表示が配布物に含まれる
- [ ] まとめ方の選定理由が ADR に残っている
