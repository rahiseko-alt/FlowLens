# #8 Typing Activity と Operation Type を記録し、文字は残さない

## Parent

https://github.com/rahiseko-alt/FlowLens/issues/3

## What to build

偽のキー入力の観測を流すと、ウィンドウごとの入力の回数と継続時間（Typing Activity）と、Ctrl+C / X / V・Enter・Tab・Escape・ショートカット起動（Operation Type）が保存される。入力された文字・IME の確定内容は保存されない。パスワード欄での入力は回数も含めて何も残らず、そうした時間があったことだけが残る。

## Acceptance criteria

- [ ] 文字を含む偽のキー入力を流しても、書き出したファイル全体を検索してその文字列が見つからない
- [ ] Typing Activity の回数と継続時間がウィンドウごとに正しい
- [ ] Operation Type が時刻・アプリつきで残る
- [ ] パスワード欄での入力は回数も残らず、「パスワード欄の時間があった」ことだけが残る
