# #16 Windows の入口: キー・Clipboard・UI 部品・ブラウザ

## Parent

https://github.com/rahiseko-alt/FlowLens/issues/3

## What to build

本物の Windows で、キー入力（回数と Operation Type のみ）、Clipboard の変化（中身を読まない）、クリック・フォーカスした UI 部品、ブラウザのアドレスを検出して中核に流す薄い入口を作る。DeskMate の `input_hooks`・`clipboard`・`uia_tree`・`browser_url` を、本文を読む処理を消したうえで流用する。パスワード欄の判定の不具合を直す。

## Acceptance criteria

- [ ] 実機で文字を入力しても、書き出したファイルにその文字が無く、回数だけがある
- [ ] 実機で Chrome から Excel へコピー＆貼り付けすると、Clipboard Transfer が1件残り、中身は無い
- [ ] 実機でパスワード欄に入力すると、回数も残らない
- [ ] Enter で入力欄の値を読む処理、TextPattern・Value を読む処理が入口に存在しない
- [ ] 実機での確認手順が手順書に残っている
