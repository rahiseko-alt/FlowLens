# #10 Control Metadata とブラウザのドメインを記録する

## Parent

https://github.com/rahiseko-alt/FlowLens/issues/3

## What to build

偽のクリック・フォーカスの観測を流すと、操作された UI 部品の Control Metadata（ControlType、AutomationId、ClassName、FrameworkId、状態）が保存される。部品の Name・Value・表示テキストは保存されない（ADR 0002。Name は見分けが付くと確かめられるまで保存しない）。ブラウザのアドレスはドメインだけが残る。

## Acceptance criteria

- [ ] Name・Value に文字列を持つ偽の観測を流しても、書き出したファイル全体を検索してその文字列が見つからない
- [ ] Control Metadata の各項目が残る
- [ ] `https://example.com/customer/123?token=abc#x` の観測から `example.com` だけが残り、パス・クエリ・フラグメントは見つからない
- [ ] http / https 以外のアドレスは残らない
