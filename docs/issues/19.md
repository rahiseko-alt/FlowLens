# #19 コンサルタント向けの手順書

## Parent

https://github.com/rahiseko-alt/FlowLens/issues/3

## What to build

開発者本人がいなくても、コンサルタントが Diagnostic Export を 7-Zip で開き、中のデータを読み、Claude Code に渡して分析できる手順書を作る。過去分と記録分の違い、題名が記号であること（中身は報告会で社員に聞く）を説明する。書き出しに同梱する `README.txt` も同じ内容の要約にする。

## Acceptance criteria

- [ ] 7-Zip でパスワード付きファイルを開く手順がある
- [ ] 同梱ファイル（SQLite、`manifest.json`、`summary.json`、`redaction_report.json`）の意味と、主な表の読み方がある
- [ ] Claude Code への渡し方と、最初に投げる問いの例がある（全記録をそのまま渡さない）
- [ ] 過去分と記録分の粒度の違いが書かれている
- [ ] 偽の観測から作った書き出しファイルで、手順どおりに開いて問い合わせできることを確かめている
