# MVP で作る項目（柱11本からの割り出し）

`docs/product-overview.md` の「支える柱」1本ずつについて、満たすために作る項目を並べる。
流用・新規の区別は `docs/research/deskmate-survey.md` の5分類による。

## 柱1: インストーラーだけで入る

- 記録の本体を1つの実行ファイルにまとめる（Python 不要）。まとめ方は依存を確かめて選ぶ
- インストーラー（スタートメニューへの登録、ログイン時の自動起動の登録）
- 実機で入れて動くかの確認手順

## 柱2: ログインすると自動で記録が始まり、記録中と表示される

- 初回の説明画面（目的、PC内に保存、AI・外部送信なし、文字は残さない、いつでも止められる、過去30日分も読むこと）。同意するまで記録も読み込みもしない
- ログイン時の自動起動、二重起動の防止
- 画面右下の常駐アイコン（記録中／一時停止中が見分けられる）
- 状態の画面（記録中か、収集開始日、記録済み時間、データ使用量）
- 止まった処理の自動復旧（強制終了・スリープ・再起動のあと）

## 柱3: アプリ、順番、使った時間を記録する（操作していない時間・ロック中は除く）

- 前面アプリの切り替えの記録（流用: `win_events.py`）
- App Session の開始と終了の記録（新規）
- 操作していない時間（idle）の検出（小変更: `activity_feed.py`）
- ロック・スリープ・セッション切断の検出（新規）
- ウィンドウタイトルは、読めない記号と拡張子だけを残す（ADR 0003）

## 柱4: ボタンの種類、コピーと貼り付けの流れ、入力した回数を記録する

- クリック・フォーカスした UI 部品の Control Metadata（小変更: `uia_tree.py`）
- Operation Type（Ctrl+C / X / V、Enter、Tab、Escape、ショートカット）（大幅変更: `input_hooks.py`）
- Typing Activity（回数と継続時間）（大幅変更: `input_hooks.py`）
- Clipboard Transfer（Copy と Paste の組、元と先のアプリ、種類、長さ）（大幅変更: `clipboard.py`、Paste 検出は新規）
- ブラウザはドメインまで（小変更: `browser_url.py`）

## 柱5: 文字、コピーした中身、パスワード、画面は残さない

- 本文を読む処理そのものを消す（入力欄の値、TextPattern、Clipboard 本文、撮影）
- パスワード欄の判定の不具合を直す
- データベースを小さく作り直し、本文の列を持たせない
- 「残していないこと」を確かめるテスト

## 柱6: 一時停止ができ、記録しないアプリを指定できる

- 常駐アイコンから一時停止・再開（流用: `capture_control`、小変更: `fusion/control.py`）
- 記録しないアプリの設定画面
- 除外判定を UI 操作・Clipboard・URL の記録すべてに効かせる（DeskMate では撮影にしか効いていなかった）
- 除外中は「除外中だった時間」だけを残す

## 柱7: ボタン1つで、期間を選んで1つのファイルに書き出せる

- 書き出しの画面（期間: 過去7日／14日／30日／すべて／日付指定）
- 書き出し時の再無害化（除外アプリの記録、URL、不要な項目）
- 同梱ファイル: データ本体（SQLite）、`manifest.json`、`summary.json`、`redaction_report.json`、`README.txt`
- 保存先は社員の手元（既定はデスクトップ等、【曖昧】場所は作るときに決める）

## 柱8: 書き出すファイルはパスワードで暗号化される（AES-256）

- パスワードを入力して AES-256 の ZIP を作る（独自方式は禁止。実績のある部品を使う）
- 7-Zip で開けることの確認

## 柱9: 別の PC で開き、Claude Code で分析できる

- コンサルタント向けの手順書（開き方、データの読み方、Claude Code への渡し方）
- MVP の Analyst 側はこの手順書だけ。繰り返しを見つけるプログラムは、実データが手に入ってから作る

## 柱10: 外部へ通信せず、アンインストールもできる

- 通信する部品を持ち込まない（REST・AI・更新確認などを削除）
- 外部通信が無いことを確かめるテスト
- アンインストーラー（記録データを消すか残すかを選べる）

## 柱11: 入れた直後に、過去30日分の足跡を読み込む（Past Import、ADR 0004）

- 読み込む元ごとの読み取り: イベントログ（システム・セキュリティ）、SRUM、UserAssist、最近使ったファイル・ジャンプリスト、Office の最近使ったファイル、Chrome / Edge の閲覧履歴（すべて新規）
- 読んだものを記録分と同じ無害化にかける（題名・ファイル名は記号化、閲覧履歴はドメインだけ）
- 過去分か記録分かを区別して保存する
- 初回の説明画面に、読み込む元の一覧と元ごとの選択を足す（初期状態はすべて選択）
- 外した元を後から読み込むボタン
- 読み込みの進み具合と、元ごとに読めた件数・読めなかった理由の表示
- 管理者権限が無いと読めない元の扱い（【曖昧】インストーラーの権限次第。実機で確かめる）
- 書き出しと `summary.json` に過去分を含める（区別したまま）

## 柱の外にあるが、元の仕様書にあるもの

- 記録データの削除画面（今日／過去7日／過去30日／すべて、確認つき）: MVP に含める
- 保存期間（初期値30日。過ぎた記録を自動で消す）: MVP に含める
- 障害調査用のログ（業務データを書かない、ローテーション）: 柱2の自動復旧に含めて作る
