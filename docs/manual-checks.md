# Windows 実機での確認手順

自動テスト（`python -m pytest`）は、記録の中核と閲覧履歴の読み取りを確かめます。Windows とやり取りする部分（アイコン、フック、ロック検出、インストーラーなど）は自動テストが無いため、この手順で実機で確かめます。
結果は各項目の「結果」欄に書き、問題があれば Issue にします。

## 0. 準備

- Windows 10 または 11。管理者でない普段のアカウントで行う（社員と同じ条件）。
- 配布物を作る（開発者の PC で）:

  ```
  pip install -e ".[windows,dev]" pyinstaller
  pyinstaller installer/flowlens.spec --distpath dist
  "C:\Program Files (x86)\Inno Setup 6\ISCC.exe" installer\flowlens.iss
  ```

- 確認用に、書き出しファイルを開く別の PC（または同じ PC）に 7-Zip を入れる。

## 2. 記録（#15, #16）

| # | 手順 | 期待 | 結果 |

| 2-1 | Chrome → Excel → Outlook と数分ずつ使う | 書き出しの `app_sessions` にその順で並ぶ | |
| 2-2 | 何も触らず7分待ち、戻る | その7分のうち、最後の操作以降は `app_sessions` に入らない | |

| 2-4 | スリープして復帰 | スリープ中の時間が入らない | |

| 2-6 | Web のパスワード欄に入力 | `is_password = 1`、`keystroke_count = 0` | |

| 2-11 | Web ページの入力欄に「yamada.taro」と入力してからページを移動 | `browser_domain` に yamada.taro が無い | |
| 2-12 | パスワード欄で Enter を押す／貼り付ける | その Enter と Ctrl+V は `operation_events` にも `clipboard_transfers` にも無い | |
| 2-13 | ログ（`%LOCALAPPDATA%\FlowLens\logs\collector.log`）を見る | 「input focus failed」などが繰り返し出ていない | |

## 3. 一時停止・除外・削除・書き出し（#18, #20）

| # | 手順 | 期待 | 結果 |
| --- | --- | --- | --- |
| 3-1 | アイコン → 一時停止する | アイコンが警告の形になり「一時停止中」。その間の操作は記録されない | |
| 3-2 | 一時停止のまま再起動 | 一時停止のまま | |
| 3-3 | 設定 → 記録しないアプリに `notepad.exe` | メモ帳を使った時間は `excluded_intervals` だけ | |
| 3-4 | 設定 → 過去の足跡 → 閲覧履歴を読み込む | 読み込み画面が出て、`browser_events` が入る | |
| 3-5 | 設定 → 記録の削除 → 今日 | 今日（日本時間の0時以降）の記録だけが消える | |
| 3-6 | 設定 → 書き出し → 過去30日、パスワード | デスクトップに1ファイル。7-Zip でパスワードを入れると5ファイルが出る | |
| 3-7 | 状態を見る | 収集開始日が同意した日、記録済みの時間とデータ使用量が出る | |
