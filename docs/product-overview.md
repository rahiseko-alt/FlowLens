# FlowLens とは

## 目的

「何を自動化したいですか」とお客様に聞かなくても、普段の PC 操作から、自動化すべき繰り返しの仕事をこちらで見つけられるようにする。

## 一言で（非エンジニア向け）

1か月いつもどおり働くだけで、自動化すれば時間を減らせる仕事の一覧が届きます。

## 誰がどう使うか

```
【社員（Client PC を使う人）】
  ① 自分でインストーラーを実行し、最初の説明に同意する
  ② 約30日、いつもどおり仕事をする（記録は自動）
     ├ 画面右下のアイコンで「記録中」かどうかがいつでも見える
     └ 見られたくない時は一時停止、記録しないアプリも指定できる
  ③ 「診断データを書き出す」を押す → 暗号化された1ファイルが手元に保存される
         │
         │ 社員が好きな方法で渡す（メール添付・USB・共有フォルダなど）
         ▼
【コンサルタント（Analyst 側）】
  ④ 分析用 PC でファイルを開く
  ⑤ プログラムで操作の流れを集計し、繰り返しを見つける
  ⑥ AI（Claude Code 等）で「何の業務か・自動化できるか・何分減るか」を評価
  ⑦ 業務改善の候補をまとめたレポートを作る
         │
         ▼
【お客様（担当者・責任者）】
  ⑧ レポートを見て、実際の業務内容をコンサルタントに説明する
  ⑨ 候補を1つ選び、試作 → 確認 → 本格的に自動化
```

## 決まっていること

- インストールするのは社員本人。管理者による一括配布は前提にしない。
- 診断ファイルの渡し方は製品で決めない。Collector の役目は、手元に1ファイルとして保存するところまで。渡し方は社員とコンサルタントが自由に選ぶ。メール添付など、途中で第三者のサーバーを通る渡し方がありうるので、診断ファイルは暗号化する。
- コンサルタントは基本的に開発者本人だが、別の人が分析することもある。そのため、Analyst 側の手順は、開発者本人がいなくても再現できる形で残す。
