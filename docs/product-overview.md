# FlowLens とは

## 目的

「何を自動化したいですか」とお客様に聞かなくても、普段の PC 操作から、自動化すべき繰り返しの仕事をこちらで見つけられるようにする。

## 一言で（非エンジニア向け）

1か月いつもどおり働くだけで、自動化すれば時間を減らせる仕事の一覧が届きます。

## 価値

- **お客様（責任者）**: ヒアリングでは出てこない、あるいは声の大きい人に偏る自動化の候補を、実際の回数と時間という証拠つきで、効果の大きい順に選べる。
- **社員**: 回答や聞き取りへの協力がほとんど要らない。中身は残らず、記録はいつでも止められる。
- **コンサルタント**: 聞き取りの工数が減り、「毎月180分の転記作業」のように数字で提案できる。自動化の試作と本格導入という次の仕事の入口になる。
- **ほかの方法との違い**: お客様の PC で AI を動かさず、外部にも送らず、中身も保存しないので、情報管理の厳しい会社でも導入の許可を得やすい（推測。未検証）。
- **最大の不確かさ**: 中身を保存しない状態で、業務を見分けられる精度が出るか。実データで確かめるまでわからない。

## 誰がどう使うか

```
【社員（Client PC を使う人）】
  ① 自分でインストーラーを実行し、最初の説明に同意する
  ② 約30日、いつもどおり仕事をする（記録は自動）
     ├ 画面右下のアイコンで「記録中」かどうかがいつでも見える
     └ 見られたくない時は一時停止、記録しないアプリも指定できる
  ③ 「診断データを書き出す」を押す → 暗号化された1ファイルが手元に保存される
         │
         │ 社員が好きな方法で渡す（メール添付・USB・共有フォルダなど）
         ▼
【コンサルタント（Analyst 側）】
  ④ 分析用 PC でファイルを開く
  ⑤ プログラムで操作の流れを集計し、繰り返しを見つける
  ⑥ AI（Claude Code 等）で「何の業務か・自動化できるか・何分減るか」を評価
  ⑦ 業務改善の候補をまとめたレポートを作る
         │
         ▼
【お客様（担当者・責任者）】
  ⑧ レポートを見て、実際の業務内容をコンサルタントに説明する
  ⑨ 候補を1つ選び、試作 → 確認 → 本格的に自動化
```

## 決まっていること

- インストールするのは社員本人。管理者による一括配布は前提にしない。
- 診断ファイルの渡し方は製品で決めない。Collector の役目は、手元に1ファイルとして保存するところまで。渡し方は社員とコンサルタントが自由に選ぶ。メール添付など、途中で第三者のサーバーを通る渡し方がありうるので、診断ファイルは暗号化する。
- コンサルタントは基本的に開発者本人だが、別の人が分析することもある。そのため、Analyst 側の手順は、開発者本人がいなくても再現できる形で残す。

## 実装してはいけない機能

1. **中身を残す機能**: キー入力の文字、入力欄の値、IME で確定した文字、パスワード、API キー、トークン、Cookie、セッション ID、Clipboard の本文、メール・チャット・文書・Web ページの本文、画面の撮影と文字の読み取り（MVP では撮影する処理そのものを持たない）、URL のクエリ文字列やトークン。
2. **Client PC で AI を使う機能**: LLM の内蔵、ローカル AI（Ollama など）、外部 AI サービスの呼び出し、MCP、AI チャット、AI による要約。
3. **こっそり動く・外へ送る機能**: 記録中であることを隠す、気づかれないようにインストールする、外部サーバーへ自動で送る、利用状況やエラー報告の自動送信、遠隔操作。
4. **人を評価する機能**: 生産性スコア、従業員ランキング、人事評価、組織単位の管理画面。
5. **範囲外の機能**: 業務の自動実行（RPA）、メールの自動送信、クラウドサービスや SaaS の管理画面、独自に考えた暗号方式。
6. **社員本人の主導を崩す機能**: 会社がまとめて社員の記録を集める仕組み、社員本人が記録を止められない設定（管理者ロック）。

## MVP のゴール

社員が入れて放っておくだけで、中身を残さずに業務の流れが記録され、安全な1ファイルで渡せる状態。

### 支える柱（すべて満たしたら MVP 完成）

1. インストーラーだけで入る（Python などの準備は要らない）
2. ログインすると自動で記録が始まり、記録中と表示される
3. アプリ、順番、使った時間を記録する（操作していない時間・ロック中は除く）
4. ボタンの種類、コピーと貼り付けの流れ（どのアプリからどのアプリへ）、入力した回数を記録する
5. 文字、コピーした中身、パスワード、画面は残さない
6. 一時停止ができ、記録しないアプリを指定できる
7. ボタン1つで、期間を選んで1つのファイルに書き出せる
8. 書き出すファイルはパスワードで暗号化される（AES-256）
9. 別の PC で開き、Claude Code で分析できる
10. 外部へ通信せず、アンインストールもできる

### MVP では作らないもの

画面の撮影、ブラウザの拡張機能、ファイル操作の把握。

### 補足

- 暗号化は当初の仕様書では後回しにしてよいとされていたが、MVP に含める。作る手間が小さく、後回しにすると暗号化していないファイルをお客様に渡してしまう危険があるため。
- AES-256 で暗号化したファイルは、Windows の標準機能では開けない（[Microsoft Support](https://support.microsoft.com/en-us/windows/experience/storage-filemanagement/zip-and-unzip-files)）。コンサルタントの PC には 7-Zip などを入れる。社員の PC には追加で何も要らない。
