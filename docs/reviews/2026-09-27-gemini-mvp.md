# Gemini 実装（gemini/mvp、PR #23）の点検結果

- 対象: https://github.com/rahiseko-alt/FlowLens/pull/23 （main との差分、21コミット）
- 方法: 決まりごと（`GEMINI.md`・ADR 0001〜0005）と仕様（`docs/issues/03〜22`）の2軸を、別々の点検役が確認した。重大な漏れは、実際にコードを動かして再現した。
- 結論: **このままでは取り込めない。** 報告書では #5〜#21 が「完了」となっているが、実際に仕様どおりなのは #5 と #7 だけ。書き出したファイルに生の個人情報が入る経路が3本あり、Windows 版は同意した直後に止まる。

## Standards（決まりごと）

### 違反（重大な順）

1. **題名の一部が「拡張子」として残る**（ADR 0003）。`crypto.py:53` は、点の後ろにある短い語をすべて拡張子とみなす。例:「Re: call John.Smith - Outlook」から `.smith` が残る。ファイル名も同じ処理を通る。
2. **アプリ名を無害化していない**（ADR 0003・0004）。過去分では UserAssist の項目名がそのままアプリ名になる。「給与明細_山田.xlsx」が書き出しにそのまま出ることを再現した。
3. **除外アプリが、閲覧履歴とシステムの記録に効かない**（ADR 0002）。chrome.exe を除外しても、閲覧したドメインが書き出しに出ることを再現した。
4. **書き出し時に URL を再度無害化していない**（ADR 0002）。
5. **読んではいけない中身を読んでいる**（ADR 0002・0004）。対象は、閲覧履歴の URL 全体（`past_import.py:392`）、入力欄の値の0.5秒ごとの読み取り（`input_watcher.py:193,202`）、Clipboard の本文（長さを数えるためだけに読む）。保存はしていないが、「読む処理を持たない」という決まりに反する。
6. **中核のデータ型に、本文用の項目がある**（`raw_text`、`raw_content`、`name`、`value` など）。
7. **Linux で試験が通らない**（`GEMINI.md` 3章）。`tests/test_issue_21.py` が Windows 用の部品を読み込んでいる。また、実行時に自動でできる中間ファイル（`__pycache__/*.pyc`）が7件入っている。

### 判断が要る点

- 一時停止中でも、過去分の読み込みが止まらない。
- 書き出しの途中で、暗号化していない一時ファイルを作る。異常終了すると残る。パスワードが空だと、途中までの ZIP が残る。
- 自動化用の部品 ID に、Web 画面では中身が入ることがある。
- 試験の一部は、暗号化された ZIP の中身を文字列で検索しているため、失敗しようがない。

## Spec（仕様どおりか）

### 動いているように見えて誤り（重大な順）

1. **同意した直後にアプリが止まる**（#18）。記録の部品を、存在しない引数名で呼んでいる（`app.py:97-107`）。
2. **配布用の実行ファイルが何もしない**（#21）。起動口が無い。存在しない部品も参照している。
3. **離席のたびに5分が作業時間に加わる**（#6）。離席と判定した時刻で区切っているため。試験は、偽の入力を離席の開始時刻にすることでこれを隠している。
4. **入力欄の値と Clipboard の本文を読んでいる**（#16）。
5. **キー入力の記録が配線されていない**（#8・#9・#16）。実機では、入力の回数も操作の種類も貼り付けの検出も記録されない。
6. **ロック・スリープ・切断を検出していない**（#15）。Windows への通知の登録が無い。
7. **保存期間による自動削除が自動で動かない**（#12）。
8. **読み込み直すと重複する**（#14）。UserAssist の時刻を作り出している。Office の記録には時刻が無いと現在時刻を入れている。SRUM は中身が空のまま「成功」を返す。
9. **過去の閲覧履歴に除外が効かない**（#14）。
10. **読めなかった理由が隠れる**（#14）。閲覧履歴の失敗も「成功」になる。
11. **書き出しの期間の境目と件数がずれる**（#5・#11）。
12. **「今日」の削除が、日本時間の朝9時で区切られる。**
13. **集計の過去分と記録分が一部混ざる**（#13）。

### 足りないもの

- 常駐アイコンが無い（#18）。読み込みの進み具合の表示、自動復旧、一時停止状態の保存も無い。
- 設定画面を開く手段が無い（#20）。
- 通信なしの試験が、空の期間を書き出しているだけ（#21）。
- ジャンプリストを読んでいない（#4）。

### 頼んでいないもの

- Python 製のインストーラー（Inno Setup と重複する）。1時間空いたら区切るという独自規則。0.5秒ごとの無駄な記録。

## 評価

- Windows 側: 起動・配線・検出の多くが未完成。実機で動いた形跡が無い。
