# Issue #20 実機確認手順書: 設定・削除・書き出しの画面

この手順書は、Windows 実機において FlowLens の「設定・削除・書き出し画面（SettingsWindow）」を開き、除外アプリの設定、保存期間の変更、データ削除、および暗号化 ZIP 書き出しが正常に動作することを確認する手順です。

## 前提条件
- OS: Windows 10 または Windows 11
- Python: 3.12 (Tkinter, pyzipper インストール済み)
- 実行権限: 一般ユーザー権限

## 確認手順

1. **設定画面の起動**
   Python 対話シェルまたはスクリプトで以下を実行します。
   ```python
   import tempfile
   from flowlens.core import Recorder
   from flowlens.windows.settings_window import SettingsWindow

   with tempfile.TemporaryDirectory() as td:
       recorder = Recorder(storage_dir=td)
       win = SettingsWindow(recorder)
       win.show()
   ```

2. **タブ 1: 除外アプリ設定の確認**
   - [x] 入力欄に `slack.exe` を入力して「追加」を押し、一覧に追加されること。
   - [x] 一覧から選択して「選択したアプリを削除」を押し、一覧から除外されること。
   - [x] 追加されたアプリは、以降の前面観測・打鍵・クリップボード転送において即座に除外（無害化）されること。

3. **タブ 2: 保存期間設定の確認**
   - [x] 「30日間」「60日間」「90日間」「無期限」のラジオボタンから選択できること。
   - [x] 「設定を保存」を押すと設定が保存され、指定期間を超える古い記録が自動削除されること。

4. **タブ 3: データ削除の確認**
   - [x] 削除範囲（今日、過去7日、過去30日、すべて）を選択できること。
   - [x] 「削除を実行」を押すと確認ダイアログ（「選択した範囲の記録データを完全に削除します。よろしいですか？」）が表示されること。
   - [x] 「はい」を選択するとデータが削除され、SQLite の VACUUM により空き容量が回収されること。

5. **タブ 4: 診断データの書き出し確認**
   - [x] 書き出し期間（過去7日、過去14日、過去30日、すべて、日付指定）を選択できること。
   - [x] パスワード入力欄（伏字 `*` 表示）にパスワードを入力できること。
   - [x] デフォルトの保存先が社員のデスクトップ（`Desktop/flowlens_export_YYYYMMDD.zip`）となっており、AppData などを開く操作を求められないこと。
   - [x] 「参照...」ボタンで手元の自由な場所に保存先を変更できること。
   - [x] 「診断データを書き出す」を押すと AES-256 暗号化 ZIP が生成され、完了ダイアログに保存先の完全パスが表示されること。
